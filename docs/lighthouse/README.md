# Project Lighthouse — docs

Governing design + plan for the Lighthouse IR market-intelligence engine (the `lighthouse/` module).

- **`spec_12_information_diffusion_and_flow.md`** — addendum to the locked Specs 01–11: models the
  lead/lag of information diffusion (multi-day event windows, anticipatory/leakage detection, a flow &
  positioning engine, revisable verdicts) and private-company competitive intelligence.
- **`sector_appetite_screen.md`** — feature spec: find institutions with demonstrated sector appetite
  that don't yet own a comp, scored on Capacity × Fit × Absorbability (+ dominant-style fit).
- **`phased_build_plan.md`** — gated V0.1 (chapel) → Shadow + paying-pilot validation → sequenced
  differentiation tail. The gates keep scope honest: don't fund the cathedral before a customer validates.

Specs 01–11 (the locked master architecture) live in the source Project Lighthouse Specification and
are summarized in the phased plan; Spec 12 above extends them.
